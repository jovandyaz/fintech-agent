### 2026-10-05 — Step 1, contracts and masking

- **Agent error caught, and it was mine.** The first `maskPii` passed its 51 tests, and a fresh-context adversarial reviewer told to _run_ attacks against it still found full-value leaks: only a space or dash counted as a separator, so a CLABE with dots, a no-break space, a line break or full-width digits went through untouched; masking serialized JSON let an escaped `\n` split a value; common phrasings like "el código que me llegó es 123456" or "CVV2 123" leaked; and the grouping loop was quadratic, so a 16 KB webhook body blocked the process for 45 s. Every finding became a failing test first (110 now), the masker was redesigned (NFKC, CLABE control digit, bounded windows, `maskJson` by value), and the worst case dropped to 26 ms. The lesson I keep: on a guarantee, my own tests prove what I thought of; an attacker-minded reviewer that executes code proves what I did not.
- **Hooks doing their job on me.** My user-level magic-values hook blocked two writes of the masker (unnamed Luhn constants, a repeated string literal), and the repo's guard hook reminded G6 on every edit of `mask.ts`.

### 2026-10-06 — Masking rounds 3 and 4, and a model redactor

- **Agent error caught, twice more.** The third masker passed every test and two more attack rounds still leaked: digits spelled out in words or mixed scripts, short groups joined across a sentence, a folio read as base64. Patching each pattern would never end, so the design changed: every message gets a digit budget, and at eight or more digits that are not a date, time, amount, folio or registry id, all of them are masked. Each exemption has a cap, so smuggling a number through "amounts" also trips the budget. One fix reopened an earlier leak (raising the amount cap); the earlier attack tests caught it.
- **A limit stated, then decided by the user.** A customer who deliberately encodes their own data ("cuatro siete seis…" split over sentences, a nickname for each digit) cannot be caught by deterministic rules without masking ordinary text. I showed that limit instead of hiding it; the user chose to add a Haiku redactor at intake that returns exact spans, which are masked before anything else runs. Its recall is reported in the evals, not gated, and a degraded rate above 5 % per hour raises an alert.
